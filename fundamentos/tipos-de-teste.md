# Tipos de Teste em QA

Durante os testes de software, diferentes tipos de teste ajudam a identificar falhas
em momentos distintos do sistema.

## Teste Funcional
Verifica se a funcionalidade faz exatamente o que foi especificado.

## Teste Exploratório
O QA interage com o sistema sem um roteiro fixo, buscando comportamentos inesperados
e cenários não documentados.

## Teste Negativo
Valida como o sistema se comporta quando recebe dados inválidos ou inesperados.

## Teste de Borda
Avalia limites, como campos vazios, valores máximos e mínimos.

## Teste de API
Verifica requisições, respostas, status HTTP e consistência dos dados retornados.
