# QA de Agentes IA para SaaS - Projeto Portfólio

Este projeto é um framework de testes automatizados focado em agentes de IA para SaaS, com ênfase em prevenção de erros lógicos, segurança e integração contínua. O diferencial é a integração automática com o Trello para rastreamento dos testes e uso do modelo Ollama para simular agentes de cobrança.

---

## 🚀 Objetivo

Construir um sistema robusto de QA para agentes IA que atuam em fluxos críticos de negócios, garantindo que regras de negócio sejam respeitadas e que erros sejam detectados automaticamente antes de impactar o cliente final.

---

## 🛠 Tecnologias e Ferramentas

- Python 3.12
- Ollama (modelo de IA local)
- Pytest (testes automatizados)
- Trello API (integração para mover cards e registrar resultados)
- GitHub Actions (CI/CD para execução automática dos testes)
- dotenv (gerenciamento seguro de variáveis de ambiente)
