# QA Portfolio

Repositório com exemplos práticos de atividades de Quality Assurance aplicadas a sistemas web e APIs.

O conteúdo apresenta casos de teste, registros de bugs, análises de segurança e estudos de caso baseados em cenários comuns de sistemas corporativos, com foco em regras de negócio, qualidade da informação e prevenção de falhas.

## Estrutura
- casos_de_teste: casos de teste funcionais
- testes_api: validações e registros de bugs de API
- seguranca: análises básicas de segurança
- estudos_de_caso: estudos aplicados a cenários reais
- fundamentos: conceitos e práticas de QA

Todo o conteúdo tem finalidade demonstrativa.
