# Análise de Segurança – Exposição de Dados via API

## Observação
A API permite acesso irrestrito aos endpoints de usuários,
sem necessidade de autenticação ou autorização.

## Risco
Em um ambiente real, esse comportamento poderia expor dados sensíveis,
permitindo coleta indevida de informações por usuários não autorizados.

## Impacto
Exposição de dados pessoais, violação de privacidade
e possível descumprimento de requisitos de segurança.

## Considerações
Apesar de a API ser pública e destinada a testes,
o cenário evidencia a importância de controles de acesso
em APIs reais.
