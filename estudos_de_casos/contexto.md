# Contexto do Estudo de Caso

Este estudo de caso teve como objetivo analisar a qualidade de uma funcionalidade de login
em uma aplicação Web e o comportamento de uma API pública utilizada para testes.

Foram utilizados ambientes de teste conhecidos, com foco em aprendizado e simulação
de cenários reais enfrentados por profissionais de QA em sistemas corporativos.

Escopo do estudo:
- Testes exploratórios em funcionalidade Web (login)
- Criação de casos de teste formais
- Documentação de bug funcional e de segurança
- Testes de API utilizando requisições HTTP
- Análise de riscos relacionados à segurança e exposição de dados
